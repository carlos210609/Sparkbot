# SparkBot M3–M15

## M3 — Memory & Context
Hybrid in-process memory/index contracts, provenance-aware records and bounded context assembly.

## M4 — Model Router
Provider/model candidates, tool/context constraints and deterministic cost/latency selection. NVIDIA remains the default integration.

## M5 — Typed Tools
Tool specifications include permissions, risk, cost, timeout and idempotency. Registry separates tool metadata from handlers.

## M6 — Verification
Success requires evidence. Verification levels are deterministic, execution-observed, or explicit evidence.

## M7 — Planning/Search
Candidate plans can be ranked and stagnation detected to prevent endless repeated reasoning.

## M8 — Computer Use
Browser/computer actions pass through a security checkpoint detector. CAPTCHA/OTP/2FA/password/recovery-code interactions remain manual.

## M9 — Multi-Agent
Typed blackboard lets specialist agents publish proposals and evidence before consensus.

## M10 — Security
Permissions, risk and dry-run policy are evaluated before tool execution. Critical actions are blocked from silent execution.

## M11 — Evaluation
Accuracy and Brier score are calculated deterministically from versionable cases.

## M12 — Learning
Outcome learning ranks strategies from observed results without modifying model weights or security rules.

## M13 — Observability
Run-scoped traces record stage, message, timestamp and structured metadata.

## M14 — Gateway
Session and rate-limit contracts establish a seam for authentication, queues and streaming.

## M15 — Production Gates
Readiness reports aggregate deployment checks. A capability is not declared production-ready until all required checks pass.

### Honest scope
M3–M15 establish executable contracts and local primitives. They do **not** pretend to be full distributed infrastructure, official platform APIs, model fine-tuning, or a production cloud deployment. Those integrations require their respective external systems and credentials.
